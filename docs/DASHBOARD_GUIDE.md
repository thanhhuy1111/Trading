# Operational Dashboard Guide

## React Dashboard Integration
The Operational Dashboard provides live operational status panels:
- **System Overview**: Overall component health, live trading status, open incidents count.
- **Observability & Metrics**: Prometheus `/metrics` endpoint status, SLO error budget gauges, accounting audit status.
- **Pipeline Lineage & Tracing**: Interactive causation chain timeline visualization.
- **Incidents & Audit Trail**: Operational incident lifecycle console and audit stream.
