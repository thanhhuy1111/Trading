# Execution Policy Specification

| Config Variable | Default Value | Description |
|---|---|---|
| `execution_mode` | `SIMULATION` | Execution environment mode |
| `default_tactic` | `SINGLE_MARKETABLE_LIMIT` | Execution slicing strategy |
| `slippage_bps` | `5.0` | Simulated slippage in basis points |
| `fee_bps` | `10.0` | Simulated taker fee in basis points |
| `live_trading_enabled` | `False` | Live trading strictly prohibited |
| `private_api_enabled` | `False` | Private exchange API access strictly prohibited |
